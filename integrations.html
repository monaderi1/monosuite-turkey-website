Supported today

Three explicit integration paths.

API

REST API and Swagger/OpenAPI

Use documented API definitions for exposed programmatic workflows and data access.

NESSUS

Nessus integration

Connect multiple Nessus instances, retrieve results on schedule and assign findings to corresponding assets.

SPLUNK

Splunk App

Allow authorised Splunk users to access exposed Cyobik data inside Splunk for the documented workflow.

Adapter model

FortiGate is a discovery and inventory adapter.

Not bidirectional

FortiGate connectivity is used through supported adapter logic to collect discovery or inventory evidence. It must not be presented as a generic bidirectional integration.

Data onboarding

Agents and file import are collection paths.

Controlled input

Push Based agents, Pull Based adapters and validated file import populate the asset model. They are not equivalent to generic SIEM, SOAR, EDR, NDR or ITSM connectors.
