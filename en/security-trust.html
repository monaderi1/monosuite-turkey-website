Security and trust

Technical controls for customer-controlled environments.

Cyobik's trust position is based on documented product behaviour and deployment boundaries, not unsupported certification or assessment claims.

Request a technical discussionReview controls

Customer-controlled deployment

Deploy inside supported VMware infrastructure controlled by the customer, including fully isolated air-gapped environments.

Access governance

Use granular roles and attribute-based restrictions to limit visible data and permitted operations.

Auditability

Record user and administrative activity and maintain lower-level system trace information.

API governance

Authenticated and authorised REST API access subject to role, licence, configuration and deployment policy.

Data boundary

Product data and processing remain inside the customer environment except for connections the customer explicitly permits.

Controlled updates

Use connected or offline update workflows according to environmental restrictions.

Public trust-claim boundary

The website does not currently name certifications, independent assessors or third-party validation bodies. Any future claim must be approved, current and supported by publishable evidence.
