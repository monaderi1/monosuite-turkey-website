Supported model

VMware OVF delivery for on-premises environments.

VMware virtual appliance

Deploy the supplied OVF package in supported VMware infrastructure.

On-premises operation

Keep product data and processing inside the organisation's environment except for connections it explicitly enables.

Fully air-gapped

Operate without a permanent internet connection and use controlled offline update workflows.

Platform boundary

The current public scope does not imply support for Hyper-V, KVM, direct bare-metal installation, container deployment or public-cloud marketplace images.

Operations

Connected and offline update paths.

Connected updates

Where outbound access is permitted, retrieve approved updates through the supported connected workflow.

Manual offline updates

Download approved packages outside the isolated environment, transfer them through the organisation's approved media process and apply them through Cyobik.

Configuration and data backup

Back up product configuration and operational data through the supported administration workflow.

Configuration restore

Restore product configuration through the supported workflow. This does not imply full operational-data restore.

Public availability boundary

Cyobik does not currently make public claims about High Availability, clustering, failover, disaster recovery, RPO or RTO.
